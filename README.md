# Gadaa Quest Hub

Build a high-fidelity, ultra-modern, and hyper-engaging Web Application called "Gadaa Quest" – Ethiopia’s Premier AI-Driven Oromia Cultural, Language & Tourism Gaming Ecosystem.

DESIGN & VISUAL IDENTITY SYSTEM:
- Visual Theme: Ultra-modern SaaS/Gamification design system with dark glassmorphism, glowing accents, sharp border radii, and smooth micro-interactions.
- Cultural Color Palette: Built around the traditional Oromia Flag and Gadaa cultural colors:
  * Primary Accent: Oromia Red (`#E11D48`) for action buttons, active states, and highlight rings.
  * Secondary Accent: Warm Ochre Gold (`#F59E0B`) for XP badges, level progress, and reward trophies.
  * Deep Backgrounds: Dark Obsidian Charcoal (`#090D16` and `#0F172A`) for sleek contrast.
  * Contrast Accents: Crisp Pure White (`#FFFFFF`) for typography and icons.
  * Top Decorative Accent: A subtle 4px top border accent bar featuring the tricolor Oromia flag sequence (Black, Red, White).
- Branding & Logo: In the navbar, render a premium glassmorphic badge for the "Oromia Culture and Tourism Bureau (OCTB)" featuring an stylized Odaa Tree SVG icon alongside the title "Gadaa Quest".

LAYOUT & KEY MODULES (NO BILLING / NO VAS):

1. HEADER & TOP NAVIGATION
- Displays the OCTB & Gadaa Quest logo.
- User Profile Pill showing avatar, level badge (e.g., "Level 5: Oda Explorer"), and active XP balance (e.g., "1,302 XP").
- Nav links: Dashboard, Quests, Tourism Map, Leaderboard, AI Guide.

2. HERO SECTION / DASHBOARD HUB
- "Featured Quest Banner": A sleek glassmorphic hero card featuring "Hora Harsadi Pilgrimage & Irreechaa Quest" with a animated progress bar (e.g., 68% complete) and a primary CTA "Continue Quest".
- Quick Stats Bar: Showing daily streak count, completed vocabulary puzzles, and badges earned.

3. CORE GAME MODULES (Interactive Cards)
- Module 1: "Afan Oromo Vocabulary Puzzles" — Interactive word-builder cards and daily trivia.
- Module 2: "Oromia Tourism Exploration Map" — An interactive visual map component highlighting iconic destinations like Sof Omar Caves, Kuriftu/Bishoftu Lakes, and Bale Mountains with click-to-play location quizzes.
- Module 3: "Gadaa Heritage & Cultural History" — Educational module covering Gadaa age-grades, historic landmarks, and tradition.

4. 24/7 AI CULTURAL GUIDE WIDGET
- Floating or side-panel AI Chat Assistant ("Aadaa AI") styled with a subtle gold glow.
- Includes quick-prompt chips (e.g., "Tell me about Irreechaa", "Practice Afan Oromo travel phrases", "History of Oda Nabee").

5. LEADERBOARD & REWARDS CATALOG
- Real-time Leaderboard table with top national players, regional filters (Finfinnee, Bishoftu, Adama, Jimma), and current user ranking position.
- Reward Store: Redeemable cultural badges, travel vouchers, and digital certificates.

NAVIGATION & INTERACTIONS:
- Use Framer Motion-style smooth transitions between views.
- Fully responsive layout optimized for both desktop web and mobile browsers.
- Dark mode default with rich high-contrast elements for maximum accessibility and readability.
